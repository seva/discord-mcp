# Fractal Decomposition — Advisory Pattern (Option A)

Status: ADVISORY, UNENFORCED. Verbatim protocol (`METHODOLOGY.md`, `CYCLE.md`, `HORIZONS.md`, `ROLES.md`, canonical prose, templates) is untouched. This file is the single home for the fractal-split procedure; all other surfaces point here.

Purpose: split any direction into nested Cycles (project → phase → direction → atomic step → repair sub-cycle) so Decide ranks atomic steps by marginal return.

## Rules (all UNENFORCED — no executing check in this file)

1. **Same Cycle at every node.** Each node carries: scope position, one task checkbox, one pre-declared verification statement, forecast V/P/C. Parent Finish waits on children Finish.
2. **100% rule (UNENFORCED).** Children sum to the parent — no gaps, no overlap.
3. **Single axis per sibling set (UNENFORCED).** Discovery children and build children are never siblings. One axis per parent.
4. **Decomposability.** Atomicity constrains granularity, never eligibility. A direction that outranks is decomposed and scored, never dismissed whole.
5. **Score marginal, not level (UNENFORCED).** Rank by what the next budget increment buys at current phase. Banked value never enters. Label marginal (Decide) vs standalone/component (Orient calibration) separately.

## Atomic test (UNENFORCED)

A leaf ships iff all hold: one session, one commit unit, binary done-check, single owner, failure stays local, Phase Gate passes, no unsanctioned external dependency (else surfaced, not executed).

## Scoring (restates selection function; adds nothing normative)

Recoverable steps: scalar forecast with eligibility floor. Irrecoverable-margin steps: profile per position at licensed refinement, never aggregated. P is epistemic discount only. Met threshold = eligible, never entitled. Empty feasible/eligible/choosable sets route per the selection function (sanction signal, sub-unit signal, Orient resolution).

## Test hook

Treatment / replication / control assignments, pass criteria, and forecast-vs-realized records live on the tracking issue and WaLRuS, not here. Promotion to enforced gate requires live validation recorded there first.
