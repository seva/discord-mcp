## Stages — one pass

1. **Dialectic** — thesis, antithesis, synthesis, grounded in observed evidence where any exists.
2. **Tradeoffs** — distill the for and against items.
3. **Tradeoff RAROC** — score each item, scoring a con as its mitigation, then rank.
4. **Atomic tree** — branches are tradeoffs; each leaf is one pass/fail property.
5. **Leaf RAROC + critical path** — cut leaves failing their Activation condition with the reason for each (see `CYCLE.md` Decide: floor and sub-unit signal). If none is eligible, execute nothing and surface per the `CYCLE.md` selection-function `surface` routing. Build the path to minimize operator touchpoints; mark what runs in parallel.

## Pre-delivery scan

Scan for contradictions between leaves and for arithmetic errors before delivering.

## Review point

Reply leading with the top recommendation and the file link. This is the one operator review point before Execute.

## Execute

Do reversible steps. This procedure runs operator-invoked, outside the cycle: for irreversible or outward steps (push, merge, delete, send, publish, production, saving a skill or setting), stop and ask the operator. Inside the cycle, `CYCLE.md` Autonomy governs instead — no step may require owner action; a sanctioned prompt is the only path by which an external dependency enters. Record forecasts where the project keeps them, so realized RAROC can be compared later.
